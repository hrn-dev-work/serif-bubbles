# Usage

Open `index.html` in a browser. No server is required.

## 1. Set the icons

Press "画像を選ぶ" for わたし and for メェ助. The picture is cropped to a circle with a thin gold edge. The name sits under the icon.

The picture stays in this browser. If the browser cannot store it, it still works until you close the page. With no picture, the circle shows わ or メ.

## 2. Enter one line at a time

"セリフを追加" adds a row. Choose the speaker and type up to 80 characters. The count is at the top right of the row.

"上へ" and "下へ" change the order. "削除" removes that row. An empty row is not drawn.

## 3. Paste several lines

Start each line with the speaker. A full-width or half-width colon both work.

```text
わたし：本命は内枠。直線の切れ味で差し切れるはず。
メェ助：今日の馬場は稍重。先行勢が残りやすい。
```

"末尾に追加" appends the lines. "この内容に置き換える" asks first, then keeps only the pasted lines.

A line that starts with neither 「わたし：」 nor 「メェ助：」 is skipped. Characters past 80 are cut off.

If you paste several lines into one dialogue box, they move to the bulk box.

## 4. Preview, then save

Under "書き出し", choose:

- one image per line, or one image for the whole conversation
- a transparent background, or pale green

The preview is scaled to the screen. The saved PNG is 800 pixels wide.

"PNGを保存" saves that image. "すべて保存" saves the per-line images from top to bottom. If the browser stops the series, use the button on each image.

## 5. The next visit

Icons, lines, and the export choices stay in the browser. They do not follow you to another browser, and they disappear if you clear the site data.
