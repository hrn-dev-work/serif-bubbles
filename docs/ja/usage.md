# 使い方

`index.html` をブラウザで開きます。サーバーは要りません。

## 1. アイコンを置く

右側の名前は「わたし」、左側は「メェ助」が入っています。名前の欄を書き換えると、吹き出しと、まとめて貼るときの行頭が変わります。空にすると初期値に戻ります。二人は別の名前にしてください。12文字を超える分は切り詰めます。

それぞれで「画像を選ぶ」を押します。画像は丸く切り抜かれ、金色の細い縁が付きます。名前はアイコンの下に出ます。

選んだ画像と名前は、このブラウザに残ります。保存できない場合も、開いているあいだは使えます。アイコンが無いときは、名前の先頭1文字の丸が表示されます。初期値では「わ」と「メ」です。

## 2. セリフを1行ずつ入れる

「セリフを追加」で行を足します。話し手を選び、80文字以内で書きます。文字数は行の右上に出ます。

「上へ」「下へ」で順番を変えます。「削除」でその行を消します。空の行は画像にしません。

## 3. まとめて貼る

次のように、行頭で話し手を書きます。コロンは全角でも半角でも読めます。

```text
わたし：今日は、朝の散歩で気づいたことを書きます。
メェ助：どの道を歩いたの？
```

名前を変えたあとは、その名前だけが行頭になります。「わたし：」「メェ助：」は、名前欄がその文字列のときだけ読めます。

「末尾に追加」は、いまのセリフの後ろに足します。「この内容に置き換える」は、確認のあと、貼った内容だけにします。

どちらの名前でも始まらない行は取り込みません。80文字を超えた分は切り詰めます。

セリフ欄に複数行を貼ると、下の「まとめて貼る」へ移します。

## 4. 見てから保存する

「書き出し」で次を選びます。

- セリフごとに1枚、または会話全体を1枚
- 背景は透明、または薄い緑

プレビューは画面幅に縮小しています。保存するPNGの横幅は800pxです。

「PNGを保存」でその画像を保存します。「すべて保存」は、セリフごとのとき、上から順に保存します。ブラウザが連続保存を止めたら、各画像のボタンを押してください。

## 5. 次に開いたとき

アイコン、セリフ、書き出しの選択はブラウザに残します。別のブラウザや、保存データを消したあとでは残りません。
