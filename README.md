# noteの記事に貼る吹き出しPNGを作る

[![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-0969da?style=for-the-badge)](./README.md) [![English](https://img.shields.io/badge/English-57606a?style=for-the-badge)](./README.en.md)

noteには吹き出し機能がありません。このツールは、二人の掛け合いを、記事に貼れる画像にします。名前の初期値は「わたし」と「メェ助」で、どちらも別の名前に変えられます。

`index.html` をブラウザで開くだけです。インストールも、会員登録も要りません。

## 誰向けか

noteの記事で、二人の会話を画像にして貼りたい人です。

## できること

- セリフを1行ずつ追加し、順番を変え、消す
- 名前欄の「名前：」で始まる行をまとめて取り込む。初期値は「わたし：」と「メェ助：」で、名前を変えると行頭も変わります
- 保存する前に、画面で吹き出しを確認する
- セリフごとに1枚、または会話全体を1枚のPNGで保存する
- 背景を透明か、薄い緑から選ぶ
- アイコン画像を丸く切り抜き、次に開いたときも使う

## しないこと

- セリフやアイコンを外部のサーバーへ送ること
- noteへの自動投稿
- 1つのセリフで80文字を超える入力（超えた分は切り詰めます）

## 使い始め

1. `index.html` をブラウザで開く
2. 二人の名前を確認し、アイコンを選ぶ。初期値は「わたし」と「メェ助」です
3. セリフを入れるか、まとめて貼る
4. プレビューを見て、PNGを保存する

手順の詳細は [使い方](docs/ja/usage.md) です。色、幅、ファイル名の決まりは [設計書](docs/ja/design.md) です。

## 保存されるPNG

横幅は800px、文字の大きさは30pxです。

| 内容 | ファイル名の例 |
| --- | --- |
| 左側（初期値はメェ助）の1枚目 | `serif_01_meesuke.png` |
| 右側（初期値はわたし）の2枚目 | `serif_02_watashi.png` |
| 会話全体 | `serif_all.png` |

透明を選んだとき、プレビューの格子は透けている印です。PNGには入りません。

## 文字とライセンス

Zen Maru Gothic（SIL Open Font License 1.1）をファイルに同梱しています。ライセンス全文は、開いた画面の一番下にあります。読めないときは、ヒラギノ丸ゴ、游ゴシック、メイリオの順で表示します。

エージェント（AI）向けのメモは英語のみです。`CONTEXT.md` と `docs/agents/` を見てください。
