# 吹き出し画像メーカー

競馬予想の note 記事向けに、「わたし」と「メェ助」の掛け合いを吹き出し画像（PNG）にするツールです。

## 開き方

`index.html` をブラウザで開きます。インストールもサーバーも不要です。

セリフもアイコンも、開いているブラウザの中だけで処理します。外部には送信しません。

## できること

- アイコン画像を丸く切り抜き、金色の細い縁を付けて吹き出しの横に置く
- アイコンはブラウザに保存され、次に開いたときも使える（保存できない場合も、開いているあいだは使える）
- セリフを1行ずつ追加・並べ替え・削除する
- 「わたし：」「メェ助：」で始まる行をまとめて取り込む
- 1つのセリフは80文字まで。吹き出しの幅で自動改行する
- セリフごとに1枚、または会話全体を縦に並べた1枚で書き出す
- 横幅800px、文字サイズ30px。背景は透明か薄い緑（`#DCEBD2`）
- ファイル名の例：`serif_01_meesuke.png`、`serif_02_watashi.png`、会話全体は `serif_all.png`

文字は Zen Maru Gothic です。読めないときは、ヒラギノ丸ゴ、游ゴシック、メイリオの順で代替します。ライセンスは画面一番下に全文があります（SIL Open Font License 1.1）。
